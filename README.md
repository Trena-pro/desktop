# Trena Desktop

Public Windows installers and release notes for Trena Desktop. Application source remains in the private development repository.

[Download the latest Windows installer](https://github.com/Trena-pro/desktop/releases/latest/download/Trena-Setup.exe)

The app connects to https://app.trena.pro. Pair it using your gym's bridge credentials.

Releases include SHA256SUMS.txt, source.json, update metadata, and the installer. Windows builds run on GitHub Actions and are checked for native SQLite startup, isolated preload access, and guarded IPC before publishing.

The initial installer is unsigned. Windows may display an unknown-publisher prompt.
